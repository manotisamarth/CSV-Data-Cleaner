# CSV Data Cleaner

## Overview

A simple Streamlit-based CSV Data Cleaning Tool built with Python and Pandas. It allows users to upload, clean, edit, and download CSV files.

## Features

* Upload CSV files
* Remove duplicate rows
* Handle missing values
* Rename and remove columns
* Change data types
* Edit data directly
* Reset data
* Download cleaned CSV

## Technologies

* Python
* Pandas
* Streamlit

## How to Run

pip install streamlit pandas
streamlit run CSV Data Cleaner.py
